## Windows beta: IDA 9.3 retained, IDA 9.4 preparation

This prerelease adds initial IDA 9.4 lifecycle handling while retaining the
existing IDA 9.3 behavior. **IDA 9.4 GUI compatibility is not yet verified.**
The stable release remains [v1.0.0](https://github.com/PoP-Lin/IDAPro-MuiLs/releases/tag/v1.0.0).

### Changes

- Use the optional IDA 9.4 `UI_Hooks.about_to_exit` callback to clean up while
  Qt is alive. IDA 9.3 continues using its existing unload callback.
- Prevent repeated theme, overlay, and native-hook cleanup during shutdown.
- Add a read-only runtime inventory collector and a dual-version validation plan.

### Validation and limits

- The development runtime passed **52/52 live IDA 9.3 interaction checks** and
  **11/11 offline regression checks**. The beta uses that runtime with only
  its version marker changed; the release workflow reruns offline checks.
- 24 simulated Windows resize-boundary cycles completed with repainting restored.
  This is not a mouse-drag latency benchmark.
- A separate live 9.3 shutdown check confirmed UI/native hooks and overlays were
  released. The real application exited with status 0.
- 20 plugin-required Python API definitions matched the provided 9.3/9.4 wrappers;
  early-exit lifecycle simulations passed. **No IDA 9.4 GUI test has been run.**
- `Ctrl+Alt+M` can conflict with other plugins such as IDA MCP. Use
  **Edit > Plugins > IDAPro-MuiLs: Toggle** or assign a distinct shortcut.

### Install or roll back

1. Close IDA and back up `ida_modern_ui_loader.py` and the `ida_modern_ui` folder.
2. Download **IDAPro-MuiLs-v1.1.0-beta.2.zip** below and extract it into IDA's
   `plugins` directory, replacing those two items.
3. Start IDA. Use `Ctrl+Alt+Shift+M` for settings.
4. To roll back, close IDA and replace both items with the saved pair.

The attached `.sha256` file verifies the ZIP. See the
[English tutorial](https://github.com/PoP-Lin/IDAPro-MuiLs/blob/v1.1.0-beta.2/docs/TUTORIAL.md)
and [compatibility notes](https://github.com/PoP-Lin/IDAPro-MuiLs/blob/v1.1.0-beta.2/docs/COMPATIBILITY.md).
